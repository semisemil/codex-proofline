# Explicit Preservation Exceptions

Do not over-apply the no-copy rule when exact wording is required.

## Case 1: Exact Quote

### Prompt

아래 문장을 보고서의 `사용자 원문` 항목에 그대로 인용하고, 다음 항목에서 한 문장으로 뜻을 설명해.

`이것은 재료를 확인하는 것이 아니라 조리 방법을 확인하려는 것이다.`

### Pass

- `사용자 원문`에는 문장을 정확히 보존한다.
- 설명에서는 뜻을 새로 작성하고 원문을 불필요하게 반복하지 않는다.

### Fail

- 복사를 피한다는 이유로 요구된 원문을 바꾼다.
- 원문을 보고서의 다른 부분에도 불필요하게 퍼뜨린다.

## Case 2: Style Example

### Prompt

`상태 먼저, 다음 행동 둘째` 구조만 참고해서 네트워크 오류 문구를 작성해. 예시의 제품명이나 오류 원인은 복사하지 마.

예시: `결제가 완료되지 않았습니다. 카드 정보를 확인하세요.`

### Pass

- 상태와 다음 행동의 순서만 적용한다.
- 결제, 카드 등 우연한 예시 내용은 복사하지 않는다.

### Fail

- 예시 문장을 그대로 바꾸어 쓰거나 결제 관련 내용을 남긴다.
