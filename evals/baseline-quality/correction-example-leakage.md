# Correction Example Leakage

## Prompt

다음 화면 안내문을 고쳐줘.

현재 문구: `패티가 소고기인지 확인합니다.`

이것은 햄버거 패티가 소고기인지를 확인하는 것이 아니고 햄버거 패티를 굽기 위한 방법을 보고자 함이다. 최종 화면에 들어갈 문구만 작성해.

## Pass

- 결과는 패티를 굽는 방법을 확인하는 목적만 담는다.
- 교정 문장, 잘못된 기존 문구, 사용자 지적, 수정 과정 설명이 결과에 들어가지 않는다.
- 결과가 채팅 기록 없이도 화면 문구로 바로 쓰인다.

## Fail

- 진단용 예시를 그대로 또는 조금 바꿔 결과에 넣는다.
- `사용자의 지적`, `이전 문구`, `소고기 확인이 아니라` 같은 교정 설명을 화면 문구에 넣는다.
