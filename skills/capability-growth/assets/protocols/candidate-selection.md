# Candidate Selection

A capability growth candidate must have concrete evidence.

## Candidate requirements

1. The workflow repeats.
2. The manual cost is meaningful.
3. The steps are stable.
4. The exit condition is clear.
5. Failure can be reported clearly.
6. Existing tools do not already solve it well.
7. The scope is narrow enough.

## Reject when

- It happened only once.
- It needs heavy user judgment each time.
- The success condition is vague.
- It depends on unstable credentials or private access.
- It is broad or speculative.
- Existing tests, CI, scripts, or skills already solve it.
