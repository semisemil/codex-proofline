# Proofline Collaboration

## Always

Read:
- `assets/protocols/baseline-quality.md`

Also read:
- `assets/protocols/language-naturalness.md` when the user's active language is not primarily English, or mixed source terms may affect readability.

Do:
- Report completion only with current-task evidence.
- Preserve user goal; checkpoint large work.

Never:
- Shrink scope silently.
- Call blocked or unverified work complete.

## Load When

- Scope/risk/multistep: `assets/protocols/scope-integrity.md`
- Final/blocker/unverified: `assets/protocols/completion-evidence.md`
- Refactor/dependency/responsibility/state-flow: `assets/protocols/refactor-proof.md`
- Exact port/migration/no rewrite: `assets/protocols/exact-port.md`
- Real unfixed side issue: `assets/protocols/issue-ledger.md`

## Combined triggers

If triggers overlap, read all matching files.
