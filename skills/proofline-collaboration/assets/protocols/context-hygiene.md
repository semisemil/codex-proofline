# Context Hygiene

Final artifacts should read as standalone documents, not chat logs.

## Rules

1. Separate user intent from temporary wording.
2. Do not copy casual chat phrases into final artifacts.
3. Do not include tool comparisons unless they are necessary.
4. Do not expose internal process details.
5. Convert complaints or negative constraints into positive design principles.
6. Mark examples as examples.

## Before final output

Check:

- Does this document stand alone?
- Did I remove temporary wording?
- Did I remove unnecessary comparisons?
- Did I avoid treating examples as fixed requirements?
- Did I explain the design as principles rather than chat history?
