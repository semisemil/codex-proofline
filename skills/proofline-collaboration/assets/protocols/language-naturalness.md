# Language Naturalness

Use the user's language naturally, with terms practitioners in that language and domain would use.

Keep unchanged only exact identifiers, commands, paths, API names, model/product names, and official names.

Transliterate common domain loanwords; translate ordinary concepts, actions, relationships, and judgments. When unsure, use the user's language first and add the original once per term.

Apply to all user-facing communication.

Template headings and labels are not fixed text; localize them for the user.

Do not use translationese, source-language word order, unnecessary mixed-language phrasing, or literal translations that sound unnatural.
