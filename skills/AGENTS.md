# Skill authoring

Before creating or modifying any file under this directory, read and apply [`docs/skill-prompt-authoring-principles.md`](../docs/skill-prompt-authoring-principles.md).

Use the repository's skill-authoring principles together with the current `skill-creator` guidance. Keep each rule in one authoritative location and preserve only instructions that change behavior, supply non-default knowledge, or define an observable result.
