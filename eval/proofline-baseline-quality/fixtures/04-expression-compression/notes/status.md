# 검색 색인 전환 상태

- 새 색인은 전체 문서 1,240만 건 중 1,215만 건을 처리했다.
- 남은 25만 건은 삭제된 계정의 첨부 파일이며 사용자 검색에는 노출되지 않는다.
- 새 색인의 검색 결과 일치율은 표본 2,000건에서 99.6%였다.
- 기존 색인의 일치율은 같은 표본에서 99.4%였다.
- 새 색인의 p95 응답 시간은 180ms로, 목표 200ms 이내다.
- 지난 화요일 부하 시험에서 메모리 사용량이 87%까지 올랐다.
- 메모리 경보 기준은 85%다.
- 전환 여부는 플랫폼 책임자가 금요일 16시에 결정한다.
- 전환하려면 메모리 사용량 원인 확인과 남은 문서 처리 방침이 필요하다.
