# 분석 내보내기 v1 메모

## 확정된 제약과 현재 계약

- 원본 감사 이벤트는 EU 외부로 전송하면 안 된다.
- v1에서 기존 CSV 내보내기의 필드 이름과 필드 순서는 바꾸지 않는다.
- 고객이 감사 기능을 끄면 수집된 감사 메타데이터를 7일 뒤 삭제한다. 단, 법적 보존 대상인 데이터는 삭제하지 않고 보존 기간이 끝날 때까지 유지한다.
- 현재 전송이 한 번 실패하면 사용자에게 실패를 알리고 작업을 종료한다.

## 미정 사항

- 저장 데이터의 암호화 방식은 미정이며 보안팀이 선택해야 한다.
- 자동 재시도를 추가할지는 미정이다. 현재 실패 동작을 바꾸기로 합의한 상태가 아니다.

## 대안과 제안

- 외부 분석 서비스를 사용할 수 없을 때는 수동 CSV 내보내기를 대안으로 사용할 수 있다. 자동 대체 동작은 아니다.
- 영업팀이 완료 알림 웹훅을 아이디어로 제안했지만 제품 요구사항으로 승인되지 않았다.

SLA, 데이터베이스 종류, 메시지 큐와 구현 일정은 이 메모에서 정하지 않았다.
