| 추론 강도 | 스킬 미적용 | 스킬 적용 | 감소 | 상대평가 |
| --- | ---: | ---: | ---: | --- |
| `high` | 7,329자 | 6,112자 | 1,217자 (16.61%) | 적용 3승, 동점 0, 미적용 0승 |
| `medium` | 6,965자 | 6,364자 | 601자 (8.63%) | 적용 1승, 동점 2, 미적용 0승 |
| 합계 | 14,294자 | 12,476자 | 1,818자 (12.72%) | 적용 4승, 동점 2, 미적용 0승 |

두 조건 모두 수정된 핵심 평가 기준을 6/6 통과했다. 상대평가는 같은 답변 쌍을 A/B와 B/A 순서로 각각 판정했고, 순서에 따른 우위를 확인할 수 없는 경우 동점으로 처리했다.

## 평가 요청

> 1. 스레드와 프로세스의 차이를 설명해줘. 2. 같은 프로그램이 어떤 컴퓨터에서는 빠르고 어떤 컴퓨터에서는 느린 이유가 뭐야? 3. 기술 부채가 쌓이면 개발 속도가 왜 느려져? 4. 작은 모델이 큰 모델보다 실제 서비스에서 더 유리한 경우를 설명해줘.

## 실행 조건

- 작업 모델: `gpt-5.6-sol`, 추론 강도 `high`와 `medium`
- 반복: 각 추론 강도에서 조건별 3회, 총 12회 작업 실행
- 비교: 스킬 미적용과 현재 전체 `proofline-baseline-quality` 적용
- 실행: 캐시 비활성화, 동시 실행 수 1, 매 반복에서 미적용 후 적용 순서
- 평가 모델: `gpt-5.6-sol`, 추론 강도 `low`, A/B와 B/A 교차평가

텍스트 평가기가 의미가 같은 표현을 놓친 3건은 평가식을 보완해 재판정했다. 생성된 원시 답변은 수정하지 않았다.

## 해석 범위

이 결과는 공개된 요청 하나를 각 추론 강도에서 3회 반복한 범위에 한정된다. 모든 종류의 답변에서 같은 감소율이 나온다는 뜻은 아니다. 또한 스킬 미적용과 현재 전체 스킬을 비교했으므로, 감소 효과 전부를 새 표현 압축 항목만의 효과로 분리해 해석할 수는 없다.

개별 답변과 판정 근거는 [`high`](high/result.json)와 [`medium`](medium/result.json)의 공개 결과에 포함돼 있다.
