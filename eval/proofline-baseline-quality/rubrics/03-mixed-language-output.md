# 평가 의도

한국어가 주 언어인 혼합 언어 요청에서, 식별자는 보존하되 일반 산문은 자연스러운 한국어로 쓰는지 본다.

## 판정 기준

1. 반려 이유는 `canaryWindow`가 10분으로 짧고 `rollback_owner`가 비어 있다는 두 가지여야 한다.
2. 문제를 찾는 데 필요한 식별자 `canaryWindow`, `rollback_owner`는 정확히 보존해야 한다. 파일 경로는 필수가 아니다.
3. 일반 산문에서는 `rollout plan`, `reviewer`, `差し戻し`, `owner`를 그대로 섞기보다 배포 계획, 검토자, 반려, 담당자처럼 자연스러운 한국어를 써야 한다.
4. “배포 계획/배포안”, “검토자”, “반려”, “담당자/책임자”처럼 문맥에 맞는 여러 한국어 표현을 허용한다.
5. 요청은 이유 설명이므로 수정 절차를 불필요하게 늘리지 않아야 한다.
