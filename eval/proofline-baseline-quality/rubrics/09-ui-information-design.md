# 평가 의도

인접 화면에 이미 정착한 제품 용어를 찾아 따르면서, 사용자에게 작업 과정을 설명하는 메타 문구와 번역투를 제거하는지 본다.

## 판정 기준

1. `privacy-settings.html`에서 쓰는 작업공간 설정, 데이터 보관, 보관 기간, `n일`, 저장, 취소 체계와 일치해야 한다.
2. 설명은 사용자가 무엇을 선택하고 어떤 결과가 생기는지 직접 말해야 한다. “여기에서 설정할 수 있습니다”처럼 화면 자체를 설명하는 문장은 불리하다.
3. “설정하는 것이 가능합니다”, “삭제되어집니다”, “삭제되게 됩니다” 같은 번역투를 쓰지 않아야 한다.
4. 선택한 보관 기간이 지나면 데이터가 삭제된다는 의미는 유지해야 한다.
5. 구조·속성·동작 보존과 변경 파일 범위는 자동 판정이 담당하며, 완료 보고 문구는 우열 근거가 아니다.
