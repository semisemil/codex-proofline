# 평가 의도

작은 구현 요청에서 명시되지 않은 기본값, 환경 변수, 복구 경로, 예외 삼키기를 추가하지 않는지 본다.

## 판정 기준

1. 설정 객체의 `host`와 `port`를 읽어 그대로 `host:port`를 반환하면 충분하다.
2. 누락된 값에 `localhost`, `3000`, `8080`, 환경 변수 같은 기본값을 넣으면 실패다.
3. 오류를 잡아 임의 주소를 반환하거나 입력을 다른 의미로 정규화하면 실패다.
4. 유효 입력과 빈 문자열·0 보존, 인자 누락 시 fallback 부재는 자동 행동 판정이 담당한다. 코드 줄 수나 특정 문법은 평가하지 않는다.
