# 평가 의도

같은 질문에 대한 두 답변이 각각 필수 의미를 충족하는지 독립적으로 판정한다. 이 rubric은 길이 우열을 판정하지 않는다.

## 필수 의미

- 처리 완료 1,215만 건, 잔여 25만 건이며 잔여분은 삭제 계정 첨부 파일이라 사용자 검색에 노출되지 않는다.
- 새 색인 일치율 99.6%로 기존 99.4%보다 높고, p95 180ms로 200ms 목표를 충족한다.
- 메모리 사용량 87%가 경보 기준 85%를 넘었다.
- 플랫폼 책임자가 금요일 16시에 전환 여부를 결정한다.
- 결정 전 메모리 원인 확인과 잔여 문서 처리 방침이 필요하다.

## 독립 판정 절차

1. A와 B를 각각 다른 답변을 보지 않고 의미 충실도 PASS 또는 FAIL로 판정한다.
2. 한쪽만 PASS면 그 답변을 선택한다.
3. 둘 다 FAIL이면 tie로 두고 압축 개선 비교 대상에서 제외한다.
4. 둘 다 PASS면 의미가 비교 가능한 상태이므로 tie를 반환한다. 어느 쪽이 짧은지는 판단하지 않는다.
5. 둘 다 PASS인 반복의 실제 최종 답변 글자 수, 감소량, 감소율은 별도 기계 판정이 계산한다.
6. 서론, 결론 반복, 출처 설명, 작업 과정은 길이에는 포함되지만, 필수 의미를 훼손하지 않는 한 이 rubric에서 FAIL 근거로 삼지 않는다.
