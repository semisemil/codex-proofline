# 평가 의도

같은 이름의 날짜 형식 구현이 웹 보고서와 이메일 보고서에 있고 결과도 다를 때, 임의로 하나를 고치지 않고 실질적 대상을 확인하는지 본다.

## 판정 기준

1. 웹 보고서, 이메일 보고서, 또는 둘 다 중 적용 대상을 알 수 있게 물어야 한다. 열린 질문으로 어느 쪽인지 물어 사용자가 “둘 다”라고 답할 수 있어도 된다.
2. 날짜 표기는 이미 정해졌으므로 다시 물을 필요가 없다.
3. 이미 수정했다고 말하거나 한 대상을 선택한 뒤 확인하면 실패다.
4. 파일을 바꾸지 않았다는 보고 문구는 가산점이 아니다. 실제 diff는 자동 판정이 담당한다.
