## 측정 범위

시간은 환경 준비를 제외하고 채점을 포함합니다. 비용은 기존과 동일한 고정 API 단가로 환산한 추정치이며 실제 청구액은 아닙니다. Sol의 설정 오류로 중단한 사전 시도는 표에서 제외했으며, 기록된 비용 하한은 $0.1696입니다. 진행 중 미보고 사용량은 알 수 없습니다.

조건별 단일 실행이고 Spec과 구현 분담도 실행마다 달라 일반적인 우열이나 리뷰 제거의 인과효과를 확정할 수 없습니다. 추가 검사 통과 수는 해당 13개 사례의 결과이며 전체 코드 품질이나 반복 실행 성공 확률을 뜻하지 않습니다. 메시지 가림 통과는 등록 클래스 보존까지 뜻하지 않으며, Box 참조 손실은 변경 전 코드에도 있던 한계입니다.
