## 코드 비교

**Astra** — Core는 None이 놓친 AggregateError의 기존 동작을 보존했습니다. Workflow는 클래스·공유 참조 보존과 호출 간 상태 분리에서 더 정확했습니다.

**Sol** — Core는 None보다 비용 23%·시간 26%를 줄여 외부 테스트를 모두 통과했습니다. Workflow는 일부 경로 처리를 개선했지만, 경로 가림 후 내부 프레임을 제거하는 조합에서 실패했습니다.
