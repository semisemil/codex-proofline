## Workflow 비용 상세

측정 당시 세션 역할별 API 환산 추정 비용입니다. 준비 내부의 명세 작성·검토 비용과 구현 내부의 구현·검증 비용은 각각 분리 집계되지 않았습니다.

| 단계·담당 | Astra / low | Sol / medium |
| --- | ---: | ---: |
| 준비 세션 (`coordinator`) | $0.856 | $0.575 |
| 구현·검증 주 세션 (`implementation-session`) | $1.321 | $2.371 |
| 구현 하위 에이전트 (`implementer`) | 미사용 | $0.643 |
| **합계** | **$2.177** | **$3.589** |

Sol의 하위 에이전트 비용은 2개 세션의 합계입니다. 금액은 [측정 데이터](results.json)의 `usage.cost_by_role_model`을 소수 셋째 자리까지 반올림했습니다.
